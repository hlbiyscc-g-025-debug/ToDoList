# ToDoList
## Project Overview

ToDoList is a simple task management application built with Java.
It allows users to manage their daily tasks through an interactive
terminal menu.

This project was created to practise Java programming and Quality
Assurance (QA), including writing automated tests and checking that
the application behaves as expected.

## Features

The application allows users to:

- Add new tasks.
- View all tasks.
- Mark tasks as completed.
- Edit existing tasks.
- Delete tasks.
- View completed tasks.
- Save tasks to a file.
- Load saved tasks when the application starts.

The application prevents users from adding empty tasks, tasks
containing only spaces, and duplicate tasks.

## Technologies Used

- Java 21
- Maven
- JUnit 5
- Git and GitHub
